# bible_projection
# 圣经投影系统

一款基于 **Python + PyQt6 + SQLite** 开发的桌面端圣经经文投影系统，面向教会聚会、讲道、查经、礼拜等场景使用。

系统支持经文快速检索、章节导航、经文范围显示、双屏扩展投影、字体与颜色自定义、背景图片、底注、自动滚动等功能，提供简洁直观的操作界面。

---

## ✨ 项目特点

* 📖 **完整圣经数据库**

  * 使用 SQLite 数据库存储《和合本》圣经经文
  * 支持书卷、章节、节号和经文内容查询
  * 支持整章、单节和连续经文范围查询

* 🔍 **快速经文搜索**

  * 支持书卷名称搜索
  * 支持书卷简称
  * 支持经文地址快速定位
  * 示例：

    * `约3:16`
    * `约 3:16`
    * `创1:1-10`
    * `诗23`

* 🖥️ **双屏扩展投影**

  * 主屏负责经文管理和操作
  * 扩展屏用于投影展示
  * 支持主屏与扩展屏经文同步
  * 鼠标滚轮、方向键和自动滚动均可同步

* 🎨 **自由定制显示效果**

  * 正文字体
  * 正文字号
  * 正文颜色
  * 标题字体
  * 标题字号
  * 标题颜色
  * 节号字体
  * 节号字号
  * 节号颜色
  * 底注字体
  * 底注字号
  * 底注颜色
  * 行距
  * 页面边距
  * 背景颜色
  * 背景图片

* 🖼️ **背景图片**

  * 支持自定义背景图片
  * 背景覆盖整个经文展示区域
  * 标题、经文和底注均显示在背景之上
  * 自动适应窗口大小

* ⏩ **经文滚动**

  * 手动上下滚动
  * 鼠标滚轮控制
  * 自动滚动
  * 多档速度调节
  * 支持空格暂停/继续

* 📝 **底注功能**

  * 支持自定义底注文字
  * 可单独设置字体、字号和颜色
  * 支持自定义底注区域高度

* 💾 **配置自动保存**

  * 显示设置自动保存
  * 主题设置自动保存
  * 窗口状态自动保存
  * 经文浏览历史自动保存

## 🚀 环境要求

建议使用：

* Python 3.10+
* PyQt6
* SQLite3

SQLite3 已经包含在 Python 标准库中，一般不需要额外安装。

---

## 📦 安装依赖

进入项目目录：

```bash
cd bible_projection
```

安装 PyQt6：

```bash
pip install PyQt6
```

如果项目后续提供 `requirements.txt`，也可以使用：

```bash
pip install -r requirements.txt
```

---

## ▶️ 运行项目

确保以下文件位于项目目录：

```text
main.py
bible_database.py
main_window.py
config.py
和合本.db
ui/
styles/
```

然后执行：

```bash
python main.py
```

程序启动后即可进入圣经投影系统。

## 📖 使用说明

### 1. 选择经文

通过左侧导航栏选择：

```text
旧约
 ├── 创世记
 ├── 出埃及记
 ├── 利未记
 └── ...

新约
 ├── 马太福音
 ├── 马可福音
 ├── 路加福音
 └── ...
```

选择书卷后可以继续选择对应章节。

---

### 2. 快速搜索经文

按下：

```text
Enter
```

打开搜索窗口。

可以直接输入经文地址，例如：

```text
约3:16
```

或者：

```text
约 3:16
```

连续经文：

```text
创1:1-10
```

整章：

```text
诗23
```

系统会自动解析书卷、章节和节号，并从 `和合本.db` 查询真实经文。

---

## 🖥️ 双屏投影

按下：

```text
F12
```

即可开启或关闭扩展显示。

使用双屏时：

```text
电脑主屏
    ↓
经文管理 + 操作控制

第二屏
    ↓
经文投影
```

主屏的经文内容变化后，扩展屏会同步更新。

经文滚动时：

```text
鼠标滚轮
   ↓
主屏经文滚动
   ↓
同步滚动位置
   ↓
扩展屏同步滚动
```

适合连接：

* 投影仪
* LED大屏
* 第二显示器
* 教会投影设备

---

## 🎨 显示设置

顶部工具栏中的：

```text
⚙ 显示设置
```

统一管理所有经文显示参数。

### 文字设置

可以分别调整：

```text
正文
标题
节号
底注
```

每个区域均可以独立设置：

```text
字体
字号
颜色
```

字号不限制在传统的 60px 以内，可以根据投影屏幕大小进行调整。

---

### 📐 行距设置

系统支持自定义经文行距。

例如：

```text
100%
120%
150%
180%
200%
```

可以根据投影距离和屏幕大小调整阅读效果。

---

### 🖼️ 背景设置

支持：

```text
背景颜色
背景图片
```

选择背景图片后，图片会覆盖整个经文展示区域：

```text
┌──────────────────────────┐
│          标题            │
│                          │
│  1  起初，神创造天地。   │
│                          │
│  2  地是空虚混沌……       │
│                          │
│                          │
│          底注            │
└──────────────────────────┘
```

标题、经文和底注都会显示在背景图片上方。

## 🗄️ 数据库

项目使用 SQLite 存储圣经数据。

数据库文件：

```text
和合本.db
```

Python 通过：

```python
sqlite3
```

进行数据库连接和查询。

数据库主要用于保存：

```text
书卷
章节
节号
经文内容
```

程序启动时会自动读取项目目录下的：

```text
和合本.db
```

因此无需手动配置数据库地址。

### 数据库位置

```text
bible_projection/
│
├── main.py
├── bible_database.py
├── 和合本.db
└── ...
```

如果更换电脑，只需要保证 `和合本.db` 与程序文件保持正确的目录关系即可。

## 🔧 开发说明

项目采用模块化设计：

```text
main.py
   │
   ▼
MainWindow
   │
   ├── BibleDatabase
   │
   ├── NavigationPanel
   │
   ├── SearchWidget
   │
   ├── ScriptureDisplay
   │
   ├── ToolBarWidget
   │
   └── ExtensionWindow
```

主要模块职责：

### `main.py`

程序入口，负责：

* 初始化 Qt
* 初始化配置
* 初始化数据库
* 创建主窗口

### `bible_database.py`

数据库访问层，负责：

* 数据库连接
* 书卷查询
* 章节查询
* 经文查询
* 经文范围查询
* 经文地址解析

### `main_window.py`

系统业务逻辑层，负责：

* 页面协调
* 经文加载
* 快捷键
* 双屏同步
* 设置管理
* 历史记录

### `scripture_display.py`

经文显示层，负责：

* 标题显示
* 经文排版
* 节号显示
* 字体颜色
* 行距
* 背景
* 底注
* 自动滚动

### `extension_window.py`

扩展屏显示层，负责：

* 第二屏投影
* 经文同步
* 滚动同步
* 投影窗口管理
