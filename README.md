# Bible Pro

> 简洁、易用的圣经经文阅读与投影软件

Bible Pro 是一款基于 **Python + PyQt6 + SQLite** 开发的 Windows 桌面端圣经经文阅读与投影工具，适用于教会聚会、礼拜、讲道、查经等场景。

软件采用 **主屏控制 + 副屏投影** 的工作方式：主屏负责选择书卷、章节和经文范围，并提供实时预览；副屏全屏显示经文，适合连接第二显示器或投影仪使用。

## ✨ 主要功能

### 📖 经文选择

- 内置《和合本》SQLite 经文数据库
- 支持旧约、新约及书卷简称选择
- 支持章节、起始节、结束节选择
- 未填写节号时，可直接显示整章
- 未填写结束节时，可直接显示至本章末节
- 支持连续显示与按节分段显示
- 支持快捷调整起始节和结束节

### 🔎 快速搜索

支持通过书卷简拼快速定位经文，并根据输入状态智能匹配书卷、章节和经文范围。

- 逐步匹配书卷简拼
- 多候选书卷时支持键盘选择
- 唯一匹配时自动完成书卷识别
- 简拼无法继续匹配时自动转换为文字
- 支持章节、节号及起止范围输入
- 支持 `↑ / ↓` 切换候选项
- 支持 `Space` 选择候选
- 支持 `Enter` 确认
- 支持 `Backspace` / `Delete` 快速修改
- 限制无关字符输入，减少误操作

### 🖥️ 双屏投影

- 支持第二显示器或投影仪
- `F12` 开启 / 关闭扩展显示
- `Esc` 关闭扩展显示
- 自动选择非主屏作为投影屏
- 副屏全屏显示经文
- 根据副屏分辨率自动排版
- 主屏预览与副屏显示同步
- 主屏滚动位置同步到副屏

### 📜 经文滚动

- 支持连续显示和按节分段显示
- 支持手动滚动和自动滚动
- 自动滚动速度支持 **1～9 档**
- `0` 暂停自动滚动
- `Space` 暂停 / 继续自动滚动
- `↑ / ↓` 手动滚动
- 支持鼠标滚轮滚动
- 滚动到末尾后自动停止

### 🎨 显示设置

支持自定义投影画面的显示效果：

- 正文字体、字号、颜色
- 标题字体、字号、颜色
- 节号字体、字号、颜色
- 底注字体、字号、颜色
- 行距与左右边距
- 底注区域高度
- 背景颜色
- 背景图片
- 亮色 / 暗色控制台主题

显示设置会自动保存，下次启动时恢复。

### 🕘 历史记录

- 自动保存最近使用过的经文
- 可快速重新打开历史经文
- 每条记录支持单独删除
- 支持一键清空历史记录

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 打开 / 关闭快速搜索 |
| `F12` | 开启 / 关闭扩展显示 |
| `Esc` | 关闭扩展显示 |
| `↑` / `↓` | 手动向上 / 向下滚动 |
| `←` / `→` | 减少 / 增加结束节 |
| `Ctrl + ←` / `Ctrl + →` | 减少 / 增加起始节 |
| `Space` | 暂停 / 继续自动滚动 |
| `1` ～ `9` | 设置自动滚动速度 |
| `0` | 暂停自动滚动 |

> 当焦点位于搜索框、数字输入框或列表等控件时，相关按键优先由当前控件处理。

## 📦 安装使用

### Windows 安装版

前往 GitHub **Releases** 页面下载最新安装程序，运行安装包并按照提示完成安装即可。

### 源码运行

环境要求：

- Windows
- Python 3.x
- PyQt6

安装依赖：

```bash
pip install PyQt6
```

启动程序：

```bash
python main.py
```

确保 `和合本.db`、`icon.ico`、`styles` 等运行所需资源位于项目目录。

## 🖥️ 扩展屏使用

将电脑连接到投影仪、电视或第二台显示器，并将 Windows 显示模式设置为 **扩展这些显示器**。

启动 Bible Pro 后：

1. 在主屏选择需要显示的经文。
2. 按 `F12` 开启扩展显示。
3. 副屏将全屏显示经文。
4. 主屏操作和滚动会同步到副屏。
5. 按 `Esc` 可关闭扩展显示。

## 📦 Windows EXE 打包

项目提供 `build_exe.bat`，使用 PyInstaller 生成 Windows EXE，不负责制作安装程序。

在项目根目录运行：

```text
build_exe.bat
```

打包完成后生成：

```text
dist/
└── Bible Pro/
    ├── Bible Pro.exe
    ├── 和合本.db
    ├── icon.ico
    ├── install.mark
    ├── styles/
    └── 其他运行依赖
```

`config.ini`、搜索历史、窗口状态等用户数据不会被打包。

## 📦 制作 Windows 安装程序

使用 **Inno Setup 7** 和项目中的 `Bible Pro.iss` 制作最终安装程序。

基本流程：

1. 运行 `build_exe.bat`。
2. 确认 `dist\Bible Pro\` 中的程序可以正常运行。
3. 使用 Inno Setup 7 打开 `Bible Pro.iss`。
4. 确认安装文件指向 `dist\Bible Pro\`。
5. 点击 **Build → Compile**，或按 `Ctrl + F9`。
6. 在 `Output` 目录获取安装程序。

最终文件：

```text
Output/
└── Bible Pro_Setup.exe
```

安装包应包含整个 `dist\Bible Pro\` 程序目录，但**不要加入用户配置文件**。

## ⚙️ 配置与用户数据

Bible Pro 会保存显示设置、窗口状态和历史记录。安装版运行时，用户配置保存在当前 Windows 用户的应用数据目录，与程序安装目录分离，也不会进入安装包。

| 文件 | 作用 | 随安装包提供 |
| --- | --- | --- |
| `和合本.db` | 经文数据库 | ✅ |
| `icon.ico` | 应用图标 | ✅ |
| `styles/` | 界面样式 | ✅ |
| `install.mark` | 安装版识别标记 | ✅ |
| `config.ini` | 用户配置、窗口状态及历史记录 | ❌ |
