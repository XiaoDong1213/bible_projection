# Bible Pro

> 专业的圣经经文阅读与投影软件

Bible Pro 是一款基于 **Python + PyQt6 + SQLite** 开发的桌面端圣经经文阅读与投影工具，主要用于教会聚会、礼拜、讲道、查经等场景。

系统采用「主屏控制 + 副屏投影」的工作方式：主屏负责选择书卷、章节和经文范围，并实时预览；副屏全屏显示经文。主屏滚动位置会持续同步到副屏，适合实际投影使用。

## ✨ 主要功能

### 📖 经文选择

- 内置《和合本》SQLite 经文数据库
- 支持 **旧约 / 新约 / 简称** 三种书卷选择方式
- 支持选择指定 **章节、起始节、结束节**
- 支持整章显示
- 支持快捷调整起始节和结束节
- 支持 **按节分段 / 连续排版** 切换

### 🔎 快速搜索

提供基于**书卷简拼**的智能经文搜索功能，可通过键盘快速定位书卷、章节和经文范围，减少鼠标操作。

#### 搜索内容

搜索框支持以下内容：

- 书卷简拼
- 章节号
- 节号
- 起止节范围
- 搜索分隔符

> 搜索输入会根据当前内容自动判断所处阶段，无需手动切换“书卷 / 章节 / 节号”等输入状态。

#### 智能简拼匹配

搜索采用**逐步匹配 + 自动转换**的方式：

1. 输入书卷简拼后，系统实时匹配对应书卷。
2. 当存在多个匹配结果时，显示候选书卷列表。
3. 可以使用 `↑ / ↓` 在候选结果之间切换。
4. 使用 `Space` 选择当前候选并进入下一步。
5. 当输入内容已经唯一对应某个书卷时，系统会自动完成书卷识别。
6. 书卷识别完成后，继续输入章节、节号等内容即可定位经文。
7. 如果当前输入已经无法继续匹配简拼，系统会根据输入状态自动完成书卷识别，不需要额外输入数字才能触发转换。

#### 输入限制

为了避免无效字符干扰搜索，搜索框只接受搜索功能需要的字符，包括：

- 英文字母 `A-Z / a-z`
- 数字 `0-9`
- 空格
- 常用章节分隔符
- 起止范围符号

其他无关字符不会被接受。

#### 候选列表

搜索过程中会根据当前输入动态显示候选结果：

- 候选内容实时更新
- 支持键盘选择
- 候选列表可自动展开和收起
- 提示区域会跟随候选列表高度自动调整
- 选择书卷后自动进入后续章节搜索

#### 删除与修改

搜索框支持直接使用退格键修改输入内容。

当已经完成书卷识别后，可以直接删除当前搜索内容并重新输入，无需逐个删除已经自动转换的内容。

#### 快捷操作

| 快捷键 | 功能 |
| --- | --- |
| `↑` / `↓` | 切换候选项 |
| `Space` | 选择候选 / 进入下一阶段 |
| `Enter` | 确认搜索 |
| `Backspace` | 删除输入 |
| `Delete` | 删除输入 |
| `Esc` | 关闭搜索窗口 |

搜索功能主要面向实际投影场景设计，可以在不离开键盘的情况下快速完成**书卷 → 章节 → 经文范围**的定位。

### 🖥️ 双屏投影

- 支持连接第二显示器或投影仪
- `F12` 开启 / 关闭扩展显示
- `Esc` 关闭扩展显示
- 自动选择非主屏作为投影屏
- 副屏自动全屏显示
- 预览舞台按照副屏实际分辨率排版
- 主屏预览与副屏使用一致的舞台尺寸
- 主屏滚动位置实时同步到副屏，避免双端滚动漂移
- 支持扩展窗口置顶

### 📜 经文滚动

支持连续自动滚动和手动滚动：

- 速度支持 **1～9 档**
- `0` 表示暂停
- `↑ / ↓` 手动滚动
- 鼠标滚轮手动滚动
- `Space` 暂停 / 继续自动滚动
- 自动滚动采用像素级推进，并根据刷新节奏更新显示
- 滚动到末尾后自动停止

### 🎨 显示设置

提供独立的显示设置界面，可以分别调整：

- 正文字体、字号、颜色
- 标题字体、字号、颜色
- 节号字体、字号、颜色
- 底注字体、字号、颜色
- 行距
- 左右边距
- 底注区域高度
- 底注文字
- 背景颜色
- 背景图片

支持 **亮色 / 暗色** 两套控制台主题，相关显示设置会保存到本地配置中，下次启动自动恢复。

### 🕘 历史记录

- 自动记录最近使用过的经文
- 历史记录可直接重新打开
- 每条记录支持单独删除
- 支持一键清空历史
- 从历史记录打开经文时不会重新排列历史列表

### 🪟 界面细节

- 左侧书卷导航固定宽度，方便快速定位
- 书卷按钮采用网格布局
- 章节、起始节、结束节使用数字输入框
- 搜索提示区域会随候选内容动态调整
- 支持明暗主题下的控件样式适配

## 🚀 安装与运行

### 1. 环境要求

- Windows / 支持 PyQt6 的桌面环境
- Python 3.x
- PyQt6

### 2. 安装依赖

在项目目录执行：

```bash
pip install PyQt6
```

### 3. 启动程序

```bash
python main.py
```

确保 `和合本.db` 位于项目根目录。

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 打开 / 关闭快速搜索 |
| `F12` | 开启 / 关闭扩展显示 |
| `Esc` | 关闭扩展显示 |
| `↑` / `↓` | 手动向上 / 向下滚动 |
| `←` / `→` | 减少 / 增加结束节 |
| `Ctrl + ←` / `Ctrl + →` | 减少 / 增加起始节 |
| `Space` | 暂停 / 继续自动滚动 |
| `1` ～ `9` | 设置自动滚动速度 |
| `0` | 暂停自动滚动 |

当焦点位于章节数字框、搜索框或列表等输入控件时，相关方向键、数字键和空格会优先交给当前控件，避免快捷键误触。

## ⚙️ 配置文件

程序运行后会根据设置生成本地配置文件，用于保存显示参数、主题、窗口状态以及历史记录等信息。

主要数据文件：

| 文件 | 作用 |
| --- | --- |
| `和合本.db` | 经文数据库，程序运行必须存在 |
| `config.ini` | 本地运行配置，自动生成 |
| `icon.ico` | Windows 应用图标资源 |

`config.ini` 不需要手动创建；删除后程序可以按默认设置重新运行。

## 📌 项目特点

本项目并不是简单的经文查询程序，而是围绕实际投影场景设计的一套桌面端控制系统，重点解决：

1. **选经效率**：书卷导航、简拼搜索、章节范围选择多种方式快速定位经文。
2. **投影稳定性**：主屏与副屏采用统一舞台尺寸，减少不同分辨率造成的排版差异。
3. **滚动同步**：副屏跟随主屏滚动位置，而不是独立运行滚动逻辑，降低长时间使用时的同步偏差。
4. **现场操作**：大量操作提供快捷键，便于投影过程中快速切换经文和调整滚动。
5. **显示自由度**：字体、字号、颜色、行距、边距、背景及底注均可根据投影环境调整。
6. **持续使用**：历史记录和本地配置自动保存，减少每次启动后的重复设置。
