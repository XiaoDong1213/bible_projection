# Bible Pro

> 面向教会聚会、礼拜、讲道与查经场景的 Windows 圣经经文阅读与双屏投影软件。

Bible Pro 是一款基于 **Python + PyQt6 + SQLite** 构建的 Windows 桌面应用。它将经文选择、经文阅读、全文搜索、显示设置、历史记录和扩展屏投影整合在一个工作流中。

软件采用 **主屏控制 + 副屏投影** 的模式：主屏用于选择和控制经文，副屏用于向投影仪、电视或第二显示器全屏展示经文。

---

## ✨ 当前功能

### 📖 书卷、章节与经文选择

- 支持圣经旧约、新约书卷选择。
- 支持书卷简称及快速定位。
- 支持章节、起始节、结束节选择。
- 支持整章显示。
- 支持从指定起始节显示到本章末节。
- 支持连续显示和按节分段显示。
- 支持通过方向键快速调整经文范围。
- 已打开的经文会进入历史记录，便于再次使用。

### 🔎 快速经文定位

快速搜索用于日常投影过程中快速定位书卷、章节和经文范围。

支持：

- 书卷简拼逐步匹配。
- 多候选书卷时继续输入进行筛选。
- 唯一匹配后自动完成书卷识别。
- 方向键选择候选书卷。
- `Space` 选择候选。
- `Enter` 确认。
- `Backspace` / `Delete` 修改输入。
- 章节、节号及起止节范围输入。
- 对无关字符进行限制，减少错误输入。

### 🔍 经文全文搜索

Bible Pro 当前提供独立的 **经文全文搜索** 模块，并通过功能开关控制是否启用。

- 支持单关键词和多关键词搜索。
- 支持模糊匹配。
- 支持精确包含匹配。
- 支持“全部关键词”匹配与“任一关键词”匹配。
- 支持选择搜索范围。
- 搜索范围覆盖旧约、新约全部书卷，并可按书卷筛选。
- 搜索结果采用分页查询，避免结果过多时一次性加载大量内容。
- 搜索结果显示书卷、章节、节号及经文内容。
- 可从搜索结果直接定位到对应经文。
- 可从搜索结果直接投影对应经文。
- 搜索面板采用独立窗口，不改变原有书卷章节选择逻辑。
- `Ctrl + F` 打开或关闭经文全文搜索。

### 🏷️ 经文小标题

项目已将经文小标题作为独立功能进行管理，并提供功能开关。

- 小标题渲染与经文正文分离。
- 小标题可根据功能开关启用或关闭。
- 小标题属于经文显示内容的一部分，可随主屏与副屏显示流程统一处理。

> 经文搜索结果仍以实际经文内容为核心，不将小标题中的交叉引用经文作为独立搜索结果。

### 🖥️ 双屏 / 扩展屏投影

- 支持 Windows 扩展显示模式。
- 支持投影仪、电视和第二显示器。
- `F12` 开启 / 关闭扩展显示。
- `Esc` 关闭扩展显示。
- 自动寻找非主屏显示器作为投影窗口。
- 副屏全屏显示经文。
- 主屏切换经文后副屏同步更新。
- 主屏滚动位置与副屏保持同步。
- 根据副屏窗口尺寸进行经文排版。

### 📜 经文滚动

- 手动滚动。
- 鼠标滚轮滚动。
- 自动滚动。
- 自动滚动支持 **1～9 档速度**。
- `0` 暂停自动滚动。
- `Space` 暂停 / 继续自动滚动。
- `↑ / ↓` 手动调整滚动位置。
- 滚动到末尾后自动停止。

### 🎨 显示设置与主题

支持对控制台和投影内容进行显示调整：

- 正文字体、字号、颜色。
- 标题字体、字号、颜色。
- 节号字体、字号、颜色。
- 底注字体、字号、颜色。
- 行距。
- 左右边距。
- 底注区域高度。
- 背景颜色。
- 背景图片。
- 亮色模式。
- 暗色模式。

主题样式集中在 `styles/` 与 UI 主题模块中管理，搜索相关窗口也跟随当前主题适配。

### 🕘 历史记录

- 自动记录实际打开过的经文。
- 未打开的选择不会进入历史记录。
- 支持快速重新打开历史经文。
- 支持单条删除。
- 支持复制历史记录中的经文标题或简称。
- 支持清空全部历史记录。

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 确认搜索 / 打开相关功能 |
| `Ctrl + F` | 打开 / 关闭经文全文搜索 |
| `F12` | 开启 / 关闭扩展显示 |
| `Esc` | 关闭扩展显示 |
| `←` / `→` | 减少 / 增加结束节 |
| `Ctrl + ←` / `Ctrl + →` | 减少 / 增加起始节 |
| `↑` / `↓` | 手动滚动；搜索时切换候选项 |
| `Space` | 暂停 / 继续自动滚动；搜索时选择候选项 |
| `1` ～ `9` | 设置自动滚动速度 |
| `0` | 暂停自动滚动 |

> 当焦点位于搜索框、数字输入框或其他输入控件时，按键优先由当前控件处理。

## 🧩 功能开关

开发 / 发布阶段的独立功能通过 `feature_flags.py` 管理。

当前包括：

```python
ENABLE_SCRIPTURE_SEARCH = True
ENABLE_SCRIPTURE_TITLES = True
```

其中：

- `ENABLE_SCRIPTURE_SEARCH`：控制经文全文搜索模块是否启用。
- `ENABLE_SCRIPTURE_TITLES`：控制经文小标题功能是否启用。

这样可以在不同发布阶段控制功能，而不需要删除对应模块代码。

## 🛠️ 技术架构

| 技术 | 用途 |
| --- | --- |
| Python | 应用主要开发语言 |
| PyQt6 | 桌面 GUI、窗口、控件、快捷键及扩展屏 |
| SQLite | 经文数据库及书卷数据 |
| QTextDocument | 经文排版与富文本显示 |
| QSS | 亮色 / 暗色主题及控件样式 |
| PyInstaller | Windows EXE 打包 |
| Inno Setup 7 | Windows 安装程序制作 |

项目采用模块化结构，将数据库、主窗口、导航、经文显示、搜索、历史记录、主题和扩展屏等职责拆分，便于继续维护和扩展。

```text
├── LICENSE                         # MIT License

```

> 项目实际文件会随着模块拆分继续调整，上述结构以当前核心模块为准。

## 🚀 从源码运行

### 环境

- Windows
- Python 3.x
- PyQt6

安装依赖：

```bash
pip install PyQt6
```

启动：

```bash
python main.py
```

运行时需要确保项目中的经文数据库及相关资源文件可被程序正确访问。

## 📦 Windows EXE 打包

项目提供 `build_exe.bat`，用于通过 PyInstaller 构建 Windows EXE。

在项目根目录运行：

```text
build_exe.bat
```

打包后的目录通常为：

```text
dist/
└── Bible Pro/
    ├── Bible Pro.exe
    ├── 和合本.db
    ├── icon.ico
    ├── install.mark
    ├── styles/
    └── 其他运行依赖
```

### 用户配置原则

**用户配置、历史记录和窗口状态不应作为测试配置直接打入安装包。**

程序安装后应使用用户自己的运行时配置，以避免开发环境中的测试设置被带入正式安装版本。

---

## 📦 Windows 安装程序

安装程序使用 **Inno Setup 7**，配置文件为：

```text
Bible Pro.iss
```

推荐流程：

1. 运行 `build_exe.bat`。
2. 检查 `dist/Bible Pro/` 中的 EXE 能够正常运行。
3. 使用 Inno Setup 7 打开 `Bible Pro.iss`。
4. 确认安装源目录指向当前 EXE 输出目录。
5. 编译安装程序。
6. 在输出目录取得最终安装包。

正式安装包只包含程序运行所需文件，不应包含开发环境中的用户配置和测试数据。

## 🖥️ 投影使用流程

1. 将电脑连接到投影仪、电视或第二台显示器。
2. 在 Windows 中选择 **扩展这些显示器**。
3. 启动 Bible Pro。
4. 在主屏选择书卷、章节和经文范围。
5. 按 `F12` 开启扩展显示。
6. 副屏进入全屏经文投影状态。
7. 在主屏切换经文或滚动内容，副屏同步更新。
8. 使用 `Esc` 关闭扩展显示。

---

## 🔎 经文全文搜索使用流程

1. 按 `Ctrl + F` 打开经文搜索面板。
2. 输入需要搜索的关键词。
3. 根据需要选择模糊 / 精确匹配方式。
4. 根据需要选择搜索范围。
5. 执行搜索。
6. 在分页结果中查看匹配经文。
7. 点击结果可定位到经文，也可以直接请求投影。

搜索范围窗口支持旧约、新约书卷列表，并提供书卷筛选、全选和清空操作。
