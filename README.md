# Bible Pro

> 面向教会聚会、礼拜、讲道与查经的 Windows 圣经阅读、讲篇放映与双屏投影软件。

Bible Pro 基于 **Python + PyQt6 + SQLite**。主屏负责选经文、编讲篇、控放映；副屏向投影仪、电视或第二显示器全屏展示经文或讲篇。

---

## 当前功能

### 经文选择与阅读

- 旧约 / 新约书卷、简称快速定位；章节与起止节、整章或从某节到章末。
- 连续显示或按节分段；方向键调整范围。
- 实际打开过的经文进入历史，可再打开、单条删除、复制标题或清空。

### 快速定位（Enter）

日常投影时用来快速跳到书卷、章、节：

- 书卷简拼逐步匹配，多候选时继续输入或用方向键 / `Space` 选择，`Enter` 确认。
- 支持章节、节号和起止范围；无关字符会被限制。
- 每次打开为空，便于重新输入。

### 经文全文搜索（Ctrl+F）

搜索面板挂在主窗口右侧分割栏，随窗口缩放。

- **相近**（按字顺序，中间可少打）与 **一致**（须连续出现）。
- 空格分词时，同一节须全部命中（例如 `爱 盼望`）。
- 可限定旧约 / 新约 / 指定书卷；结果分页，可定位或直接投影。
- 保留最近搜索，支持单条删除。

### 经文小标题

- 与正文分开设置字体、字号、颜色；工具栏或功能开关启停。
- 主屏与副屏同步。搜索仍以经文正文为准，不把小标题里的交叉引用当成独立结果。

### 双屏投影

- Windows 扩展显示；自动选用非主屏作投影窗口，按副屏尺寸排版。
- 工具栏「扩展显示」：两块屏直接开；三块及以上可从三角菜单选输出屏，并记住上次选择。
- `F12` 开 / 关扩展屏。关闭扩展时若正在放映讲篇，会一并结束。
- `Esc`：放映中先结束放映（主屏与副屏相同）；未放映时关闭扩展。
- 主屏换经文、滚动位置与副屏同步；副屏经文不独立滚动。
- 讲篇 / 经文频道可交叉淡化，时长在显示设置中可调（`0` 为立刻切换）。

### 讲篇编辑与放映

工具栏「讲篇」打开编辑器（叠在主界面上，「返回经文」回经文界面，不弹保存；退出程序时才询问）。

**编辑**

- 多页幻灯片：文本、图片、形状、背景色 / 背景图；可拖拽画出文本框或形状。
- 格式刷、对齐 / 分布、图层顺序；撤销 / 重做（改字时优先文字级撤销）。
- 元素入场动画（淡入、飞入、缩放、擦除等）与换页过渡。
- 左侧列表可拖拽改页序；`Ctrl + A` 在列表上全选页、在画布上全选图层；`Ctrl + Shift + A` 始终全选幻灯片。
- 存档为单个 `.sermon` 包（`sermon.json` + `assets/`）；工作副本在 `sermons/`。
- 可导入 / 导出 PPTX（需 `python-pptx`）；可另存为模板。

**放映**

- `F5` 开始放映：副屏投讲篇，主屏预览与观众同画，底部出现放映栏。
- 空格 / 方向键 / 滚轮按 PPT 方式逐步出现元素，再翻页。
- 放映中须点工具栏「编辑」才能改画布；「预览」回到与观众同画。未点「编辑」时插入、格式、背景、侧栏等不可改。
- 底栏「显示经文 / 显示讲篇」只切观众画面，不结束进度。
- 「结束放映」或 `Esc` 结束会话，副屏立刻回到经文；扩展窗可继续开着。

### 经文滚动

- 手动、滚轮、自动滚动（`1`～`9` 档速度，`0` 暂停，`Space` 暂停 / 继续）。
- `↑` / `↓` 微调位置；滚到末尾自动停止。

### 显示设置与主题

控制台与投影内容可调：正文 / 标题 / 小标题 / 节号 / 底注的字体、字号与颜色，行距、左右边距、底注高度、背景色或背景图，以及亮色 / 暗色主题。讲篇与经文切换的淡化时长一并在显示设置中。

样式在 `resources/styles/` 与 `ui/themes/`。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 打开 / 关闭快速定位 |
| `Ctrl + F` | 打开 / 关闭经文全文搜索（右侧栏） |
| `F1` | 快捷键帮助 |
| `F5` | 开始放映当前讲篇 |
| `F12` | 开 / 关扩展屏（关时若正在放映会一并结束） |
| `Esc` | 放映中结束放映；未放映时关闭扩展屏 |
| `Ctrl + A` | 讲篇：列表上全选页，画布上全选图层（输入框内仍为全选文字） |
| `Ctrl + Shift + A` | 讲篇：全选幻灯片 |
| `←` / `→` | 经文：减少 / 增加结束节。放映：上一页 / 下一步 |
| `Ctrl + ←` / `Ctrl + →` | 增加 / 减少起始节 |
| `↑` / `↓` | 经文：手动滚动。放映：上一页 / 下一步。搜索：切换候选项 |
| `Space` | 经文：暂停 / 继续自动滚动。放映：下一步。搜索：选择候选项 |
| `1` ～ `9` | 自动滚动速度 |
| `0` | 暂停自动滚动 |

焦点在搜索框、数字框等输入控件时，按键先交给当前控件。放映中空格和方向键用于步进 / 翻页。

## 功能开关

独立功能由 `app/feature_flags.py` 控制，不必删模块代码：

```python
ENABLE_SCRIPTURE_SEARCH = True  # 经文全文搜索（Ctrl+F）
ENABLE_SCRIPTURE_TITLES = True  # 经文小标题
ENABLE_SERMON = True            # 讲篇编辑与放映
```

关掉后对应工具栏入口、帮助项与相关设置项不会出现。

## 技术架构

| 技术 | 用途 |
| --- | --- |
| Python | 应用主体 |
| PyQt6 | 桌面界面与扩展屏 |
| SQLite | 经文与书卷数据 |
| QTextDocument | 经文排版 |
| QSS | 亮色 / 暗色主题 |
| PyInstaller | Windows EXE |
| Inno Setup 7 | 安装程序 |

`app` 负责启动与开关，`core` 负责配置 / 数据库 / 选择模型 / 讲篇存储，`ui` 负责界面，`resources` 为只读资源，`tests` 为单测。

## 从源码运行

- Windows，Python 3.10+，PyQt6

```bash
pip install -r requirements.txt
python main.py
```

也可 `python -m app.main`。需能访问 `resources/` 中的经文库。

开发时配置在项目根目录 `config.ini`；讲篇工作副本与模板在 `sermons/`、`templates/`。安装版数据在 `%APPDATA%\bible_projection\`。

单测：

```bash
python -m pytest tests -q
```

## Windows 打包

根目录运行 `build_exe.bat`，产物一般在：

```text
dist/Bible Pro/Bible Pro.exe
```

用户配置、历史和窗口状态不应打进安装包。`build_exe.bat` 会尽量去掉 `dist` 里的个人配置。

安装程序用 Inno Setup 7 打开 `Bible Pro.iss`：先打包 EXE，确认能运行，再编译，安装包在 `dist_installer/Bible Pro_Setup.exe`。

## 使用流程

**投影经文**

1. 接好第二块屏，Windows 选择「扩展这些显示器」。
2. 主屏选好经文，点「扩展显示」或 `F12` 开扩展屏（三块及以上可从三角菜单选屏）。
3. 主屏换经文或滚动，副屏同步。`Esc` 关扩展（若正在放映则先结束放映）。

**放映讲篇**

1. 「讲篇」打开编辑器，新建或打开 `.sermon`。
2. `F5` 开始放映（需扩展屏；单屏会落到主屏窗口便于预览）。
3. 需要改内容时点「编辑」；改完点「预览」回到与观众同画。
4. 底栏翻页、切经文 / 讲篇或结束。切频道可淡入淡出，不丢进度。
5. 「结束放映」或 `Esc` 结束会话，副屏回经文；再 `Esc` 关扩展屏。

淡化时间在 **显示设置 → 布局与底注 → 讲篇/经文切换**。

**全文搜索**

`Ctrl + F` 打开面板，选相近 / 一致与书卷范围，从结果定位或投影。
