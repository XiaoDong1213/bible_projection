# 圣经投影系统

基于 **Python + PyQt6 + SQLite** 的桌面端经文投影工具，面向教会聚会、讲道、查经、礼拜等场景。

主屏负责选经与控制，副屏全屏投影；预览区按副屏分辨率等比缩放，尽量做到「所见即所得」。

---

## 功能概览

- **和合本圣经库**：SQLite 存储，支持书卷 / 章 / 节范围查询
- **左侧导航**：旧约、新约、简称网格；章节与经文起止选择
- **快速搜索**：回车打开搜索，支持 `约3:16`、`创1:1-10`、`诗23` 等写法
- **双屏投影**：`F12` 开/关扩展屏，内容与滚动同步；可置顶
- **提词器式滚动**：按像素/秒连续滚动，跟随屏幕刷新率，减少整像素跳动
- **显示定制**：正文 / 标题 / 节号 / 底注的字体、字号、颜色；行距、边距；背景色与背景图
- **按节分段**：可选按节分段排版
- **历史记录**：最近经文一键打开；点选历史不重排列表
- **主题**：暗色 / 亮色控制台风格，设置与历史自动写入 `config.ini`

## 安装与运行

### 环境

- Python 3.10 或更高
- PyQt6

```bash
cd bible_projection
pip install PyQt6
```

请确认项目根目录存在 `和合本.db`。

### 启动

```bash
python main.py
```

## 使用说明

### 选经

1. 左侧切换 **旧约 / 新约 / 简称**，点选书卷  
2. 下方设置 **章 / 起 / 止**，点 **显示所选经文**  
3. 可选打开 **按节分段**

### 搜索

按 `Enter` 打开搜索框，例如：

| 输入 | 含义 |
| --- | --- |
| `约3:16` / `约 3:16` | 约翰福音 3:16 |
| `创1:1-10` | 创世记 1 章 1–10 节 |
| `诗23` | 诗篇第 23 篇（整章） |

### 双屏投影

1. 连接第二显示器或投影仪  
2. 按 `F12`（或点工具栏「扩展显示」）全屏投影到副屏  
3. 预览区按副屏分辨率排版并缩放；扩展屏滚动由主屏驱动同步  
4. `Esc` 可关闭扩展显示；工具栏可切换扩展窗置顶  

### 滚动

- 工具栏 **暂停 / 1档 … 9档**，或数字键 `0`–`9`  
- `↑` / `↓` 手动滚；滚轮同理  
- `Space` 暂停 / 继续（记住上一档速度）  
- 自动滚动按屏幕刷新率推进，速度为像素/秒（档位越大越快）

### 显示设置

工具栏 **显示设置** 中可改：

- 正文 / 标题 / 节号 / 底注：字体、字号、颜色  
- 行距、左右边距、底注高度与文案  
- 背景颜色、背景图片  

设置写入 `config.ini`，下次启动自动恢复。

### 历史

- **历史** 页显示最近记录（最多约 30 条）  
- 点击某条只打开投影，**不重排**历史顺序  
- 书卷选择、范围显示、搜索打开会写入并置顶历史

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 打开搜索 |
| `F12` | 开/关扩展显示 |
| `Esc` | 关闭扩展显示 |
| `↑` / `↓` | 向上 / 向下滚动 |
| `←` / `→` | 减少 / 增加结束节 |
| `Ctrl+←` / `Ctrl+→` | 减少 / 增加开始节 |
| `Space` | 暂停 / 继续自动滚动 |
| `0`–`9` | 滚动速度（0=暂停） |

在章节数字框等输入控件聚焦时，方向键与空格会让出，避免误触。

## 配置与数据

| 文件 | 说明 |
| --- | --- |
| `和合本.db` | 经文与书卷元数据，须与程序同目录 |
| `config.ini` | 显示参数、主题、窗口几何、搜索/浏览历史 |

更换电脑时带上 `和合本.db`；`config.ini` 可选，没有会按默认重建。

## 模块关系（简要）

