# Bible Pro

> 专业的圣经经文阅读与投影软件

Bible Pro 是一款基于 **Python + PyQt6 + SQLite** 开发的 Windows 桌面端圣经经文阅读与投影工具，面向教会聚会、礼拜、讲道、查经等场景。

软件采用 **主屏控制 + 副屏投影** 的工作方式：主屏负责选择书卷、章节和经文范围，并提供实时预览；副屏全屏显示经文。主屏与副屏保持滚动同步，适合实际投影使用。

## ✨ 主要功能

### 📖 经文选择

- 内置《和合本》SQLite 经文数据库
- 支持旧约、新约及书卷简称选择
- 支持章节、起始节、结束节选择
- 未填写结束节时，可直接显示至本章末节
- 未填写节号时，可直接显示整章
- 支持按节分段与连续排版两种显示方式
- 支持快捷调整起始节和结束节

### 🔎 快速搜索

支持通过书卷简拼快速定位经文，搜索框会根据当前输入状态智能匹配书卷、章节和经文范围。

主要特性：

- 逐步匹配书卷简拼
- 多个候选书卷时支持键盘选择
- 唯一匹配时自动完成书卷识别
- 简拼无法继续匹配时自动转换为书卷名称
- 支持章节、节号及起止范围输入
- 支持 `↑ / ↓` 切换候选项
- 支持 `Space` 选择候选
- 支持 `Enter` 确认搜索
- 支持 `Backspace` / `Delete` 快速修改
- 限制无关字符输入，减少误操作

### 🖥️ 双屏投影

- 支持第二显示器或投影仪
- `F12` 开启 / 关闭扩展显示
- `Esc` 关闭扩展显示
- 自动选择非主屏作为投影屏
- 副屏自动全屏显示
- 根据副屏实际分辨率进行排版
- 主屏预览与副屏使用统一舞台尺寸
- 主屏滚动位置实时同步到副屏
- 支持扩展窗口置顶

### 📜 经文滚动

- 支持连续自动滚动和手动滚动
- 自动滚动速度支持 **1～9 档**
- `0` 暂停自动滚动
- `Space` 暂停 / 继续自动滚动
- `↑ / ↓` 手动滚动
- 鼠标滚轮手动滚动
- 滚动到末尾后自动停止

### 🎨 显示设置

支持对投影画面进行详细调整：

- 正文字体、字号、颜色
- 标题字体、字号、颜色
- 节号字体、字号、颜色
- 底注字体、字号、颜色
- 行距
- 左右边距
- 底注区域高度
- 底注文字
- 背景颜色
- 背景图片
- 亮色 / 暗色控制台主题

显示设置会保存到本地配置，下次启动时自动恢复。

### 🕘 历史记录

- 自动保存最近使用过的经文
- 可直接重新打开历史经文
- 每条记录支持单独删除
- 支持一键清空历史记录
- 从历史记录打开经文不会重新排列历史列表

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Enter` | 打开 / 关闭快速搜索 |
| `F12` | 开启 / 关闭扩展显示 |
| `Esc` | 关闭扩展显示 |
| `↑` / `↓` | 手动向上 / 向下滚动 |
| `←` / `→` | 减少 / 增加结束节 |
| `Ctrl + ←` / `Ctrl + →` | 减少 / 增加起始节 |
| `Space` | 暂停 / 继续自动滚动 |
| `1` ～ `9` | 设置自动滚动速度 |
| `0` | 暂停自动滚动 |

当焦点位于搜索框、数字输入框或列表等控件时，相关按键优先交给当前控件，避免快捷键误触。

## 🚀 源码运行

### 环境要求

- Windows
- Python 3.x
- PyQt6

### 安装依赖

```bash
pip install PyQt6
```

### 启动程序

```bash
python main.py
```

确保 `和合本.db` 位于项目根目录。

## 📦 Windows EXE 打包

项目提供 `build_exe.bat`，用于通过 PyInstaller 将源码打包为 Windows 桌面程序。

在项目根目录直接运行：

```text
build_exe.bat
```

打包完成后：

```text
dist/
└── Bible Pro/
    ├── Bible Pro.exe
    ├── 和合本.db
    ├── icon.ico
    ├── install.mark
    └── styles/
```

用户配置文件不会随 EXE 打包。安装版运行时会在用户目录保存自己的配置和历史记录，不会覆盖项目或安装目录中的程序文件。

## 📦 使用 Inno Setup 7 制作安装程序

PyInstaller 生成 EXE 后，可以使用 **Inno Setup 7** 制作最终安装程序。

### 基本流程

1. 运行 `build_exe.bat`。
2. 打开 Inno Setup 7。
3. 打开项目中的 `Bible Pro.iss`。
4. 确认安装文件指向 `dist\Bible Pro\`。
5. 点击 **Build → Compile**，或按 `Ctrl + F9`。
6. 编译完成后，在 `Output` 目录找到安装程序。

最终文件：

```text
Output/
└── Bible Pro_Setup.exe
```

安装程序包含程序运行所需文件，但**不会包含用户运行过程中产生的 `config.ini`、搜索历史、窗口状态等个人配置数据**。

## ⚙️ 配置与用户数据

Bible Pro 会自动保存显示设置、窗口状态和搜索历史。

源码运行时，配置保存在项目运行目录；安装版运行时，配置保存在当前 Windows 用户的应用数据目录。

主要文件：

| 文件 | 作用 | 是否随安装包提供 |
| --- | --- | --- |
| `和合本.db` | 经文数据库 | ✅ |
| `icon.ico` | 应用图标 | ✅ |
| `styles/` | 界面样式 | ✅ |
| `install.mark` | 安装版识别标记 | ✅ |
| `config.ini` | 用户配置、窗口状态及历史记录 | ❌ |

删除用户的 `config.ini` 后，程序会自动使用默认设置重新创建配置。
